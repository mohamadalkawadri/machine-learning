# Fetal Health Classification using Machine Learning

## Overview
This project investigates supervised machine learning techniques for fetal health classification using medical data.

## Technologies
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- mlxtend

## Machine Learning Models
- Perceptron
- Adaline
- Logistic Regression

## Project Features
- Exploratory Data Analysis (EDA)
- Data cleaning and preprocessing
- Train/Test split
- Feature standardization
- Model training using Gradient Descent
- Performance evaluation
- Accuracy comparison across dataset sizes and training epochs
- Data visualization

## Learning Outcomes
- Supervised Machine Learning
- Classification Problems
- Feature Scaling
- Model Evaluation
- Data Visualization
- Experimental Analysis
